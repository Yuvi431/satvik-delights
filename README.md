# Satvik Delights - Events & Caterer

> Premium Pure Vegetarian Catering and Event Planning in Jaipur, Rajasthan.

## Features
- **Grand Wedding & Engagement Catering**: Traditional royal setups, live interactive food stalls, 100% pure desi ghee delicacies.
- **Corporate & Social Gatherings**: Executive buffets, high tea, birthday celebrations, and family pujas.
- **Pure Vegetarian & Jain/Satvik**: Authentic recipes with no compromise on hygiene, taste, or traditional values.
- **Custom Event Management**: Stage backdrops, floral mandaps, lighting, and guest hospitality.

## Tech Stack
- React 19
- Vite
- Lucide React
- Vanilla CSS Design System

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
